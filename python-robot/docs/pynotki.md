## PEP <a name="pep"></a>

<b><ins>PEP (Python Enhancement Proposal)</ins></b> 

+ Dokument przedstawiający propozycję nowej funkcji języka, albo nowego procesu lub standardu.<br>

+ Dosłownie jest to propozycja dodania ulepszeń do języka python.

+ PEP-y są numerowane chronologicznie.

+ Najbardziej znane dokumenty PEP:
    
    - <em>PEP 1</em> — PEP Purpose and Guidelines (jak w ogóle pisać PEP-y)

    - <em>PEP 2</em> — Procedure for Adding New Modules

    - <em>PEP 3</em> — Guidelines for Handling Bug Reports

    - <em>PEP 8</em> — Style Guide for Python Code
    
    - <em>PEP 20</em> — The Zen of Python  
    
    - <em>PEP 257</em> — Docstring Conventions  
    
    - <em>PEP 484</em> — Type Hints

+ Do 2018 r. każdy PEP był zatwierdzany lub odrzucany osobiście przez Guido van Rossum.

+ W 2018 r. Guido van Rossum przeszedł na emeryturę i od tego czasu PEP-y zatwierdzane są przez Python Steering Council (Rada Sterująca) - organ złożony z "core developerów".
